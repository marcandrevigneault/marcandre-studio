# Video QR Implementation Plan

Goal: web encoder/decoder, Android/iOS projects, concise website presentation.
Spec: ../specs/2026-11-17-video-qr-design.md

1. Core in apps/video-qr/src/packet.ts and media.ts: tests first for exact byte round trips, out-of-order/duplicate packets, corrupt/mixed input and size limits. Local FFmpeg compression and MP4 playback fallback. Own package dependencies and build config.
2. App UI in apps/video-qr/src/main.ts, style.css and index.html: upload/trim/presets, QR generation/export, camera and PNG scanning, assembly progress, reconstructed video playback. Calls core interfaces below. Validate actual QR round trip with image decoder.
3. Native packaging: Capacitor config and generated iOS/Android projects, camera permission strings, local assets, setup/build documentation. Verify builds where installed SDKs permit; report missing SDK/signing requirements.
4. Site: Art, Projects, Video QR case study, navigation/homepage. Generate short local previews with exact attribution and original measurement metadata. Keep site prose concise.
5. Integration: app typecheck/tests/build, full site tests/build, browser encode/decode smoke, source review. Record limitations and launch instructions.

Interfaces: packet.ts exports async packVideo(data: Uint8Array): Promise<Uint8Array[]> and class PacketCollector { add(packet: Uint8Array): Promise<{received:number,total:number,complete?:Uint8Array}>; reset():void }. MAX_PACKET_BYTES=2953. media.ts exports compressVideo(file:File,options:{start:number;duration:number;width:number;fps:number;audioKbps:number},onProgress?:(message:string)=>void):Promise<Uint8Array> and playableVideo(data:Uint8Array):Promise<Blob>, cancelMedia():void. WebM input/output for packets, MP4 fallback for browsers without playback. Shared max 8 MiB assembled video, 100 MiB input, 10 seconds duration.
